# Подготовка к защите сетевого калькулятора

124 вопроса и 66 слайдов по исходному проекту C++11 с TCP и poll.

Сайт: https://alexuner.github.io/alexey-tcp-defense/

Для общего прогресса используются отдельные коды ученика и наставника. Коды, переписка и база прогресса в этом репозитории отсутствуют.

Пробный режим сохраняется в браузере. Основной прогресс хранится отдельным сервисом.

Шрифт Manrope используется по лицензии OFL, текст лицензии в assets/OFL.txt.
